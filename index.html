Контракт дизайн-системы ​

Контракт — договор между дизайном и разработкой. В нём записано, как выглядит приложение в цифрах: цвета, отступы, скругления, шрифты, размеры — и как они называются в коде Android и iOS. Разработчик берёт значения отсюда, а не измеряет в макете.

Как это работает
  1. Дизайн меняет значение — в Figma и в репозитории дизайн-системы.
  2. Выходит новый релиз. Система проверяет совместимость и пишет, что изменилось: было → стало, какие компоненты задеты.
  3. Разработка смотрит изменения и скачивает пакет.
  4. Приложение берёт значения из пакета. Поэтому Android, iOS и Figma не расходятся.

Форматы. Контракт — JSON по общепринятому стандарту дизайн-токенов DTCG (его выпускает рабочая группа при W3C, той же организации, что отвечает за HTML и CSS). Файл без переделки понимают плагины Figma и генераторы кода. Для приложений в пакете уже лежит готовый код: Kotlin для Compose и Swift для SwiftUI.

Подключение · iOS · SwiftUI

TrassirTokens.swift копируется в TrassirUIKit или добавляется в пакет отдельной целью.

swift
Text("Камера у входа")
    .font(TrassirTokens.Tr.Typography.ndBody1)
    .foregroundColor(TrassirTokens.Tr.Color.grayscale100)
    .padding(TrassirTokens.Tr.Spacing.standardPadding)
    .background(TrassirTokens.Tr.Color.grayscale800)

Имена повторяют текущий код: TrColor.grayscale800 → TrassirTokens.Tr.Color.grayscale800, переезжать можно постепенно. Светлой темы на iOS нет.

Формат и статусы
Размерыpx: 1 px = 1 pt на iOS = 1 dp на Android
ЦветаsRGB, hex
Ссылки{md.sys.dark.primary} — значение берётся из другого ключа

У каждого токена записано: с какой версии он есть, статус, имя в Compose и SwiftUI, где значение лежит в приложении (файл и строка).

Статусы. stable — можно опираться. deprecated — есть замена, ключ удалят в указанной версии. conflict — Android и iOS расходятся, записаны оба значения, целевое ещё не выбрано.

Уровень компонента. Нативный — компонент платформы как есть, меняем только тему. Нативный с настройкой — меняем размеры, форму, цвета. Свой — описан целиком. Ширина, анимации, ripple и доступность в контракт не входят.

Правила версий
ИзменениеВерсия
Поменялось значениеPATCH
Добавлен ключ, компонент или параметрMINOR
Ключ помечен deprecated с заменойMINOR
Удалён ключ, который уже был deprecatedMAJOR
Сменился тип ключазапрещено

Пока версия 0.x, ломающее изменение выходит как MINOR. Удалить ключ без deprecated в прошлом релизе нельзя.

trassir-ds.contract.json — токен в контракте

Так в файле контракта записан один токен — здесь цвет и отступ. Поля $type и $value — общепринятый формат дизайн-токенов (стандарт DTCG), их понимают сторонние инструменты. В $extensions — наши пояснения для разработки: с какой версии токен есть, как он называется в коде и где лежит в приложении.

jsonc
{
  "md": {
    "sys": {
      "dark": {
        "primary": {  // ключ md.sys.dark.primary
          "$type": "color",  // что это: color — цвет, dimension — размер, typography — шрифт
          "$value": "{color.palette.7168E8}",  // ссылка на примитив палитры или само значение
          "$extensions": {
            "ru.dssl.trassir": {
              "since": "0.1.0",  // с какой версии контракта ключ есть
              "status": "conflict",  // stable · deprecated · conflict
              "code": {  // имя в сгенерированном коде
                "compose": "TrassirTokens.Md.Sys.Dark.primary"  // Android: TrassirTokens.kt
              },
              "source": {  // где значение живёт в приложении сейчас

TrassirTokens.kt — Android · Compose

Сгенерированный код. Комментарий над токеном — где это значение было в коде приложения.

kotlin
// android/src/commonMain/kotlin/…/TrassirTokens.kt — фрагмент, полный файл в пакете
package ru.dssl.trassir.ds.tokens

object TrassirTokens {
    // Шкала отступов: общая для Android и iOS
    object Spacing {
        val s: Dp = 8.dp
        val m: Dp = 12.dp
        val l: Dp = 16.dp
    }
    object Md {
        object Sys {
            // Роли Material 3. Светлая тема — object Light, тёмная — object Dark
            object Dark {
                /** В коде: TrassirColors.md_theme_dark_primary. Конфликт «primary», значение не сведено. */
                val primary: ComposeColor = ComposeColor(0xFF7168E8)
                /** В коде: TrassirColors.md_theme_dark_onPrimary. */
                val onPrimary: ComposeColor = ComposeColor(0xFFF3EEFF)
                /** В коде: TrassirColors.md_theme_dark_surface. Конфликт «surfaceContainer», значение не сведено. */
                val surface: ComposeColor = ComposeColor(0xFF252527)
            }
            // Радиусы MaterialTheme.shapes
            object Shape {
                /** В коде: Shapes.medium. */
                val medium: Dp = 8.dp
            }
            // Типографика. Семейства в TextStyle нет: Inter берётся из ресурсов приложения
            object Typescale {
                /** В коде: Typography.labelLarge. */
                /** Шрифт: Inter. */
                val labelLarge: ComposeTextStyle = ComposeTextStyle(fontWeight = ComposeFontWeight(500), fontSize = 14.sp, lineHeight = 20.sp, letterSpacing = 0.1.sp)
            }
        }
    }
}

// Как использовать
Text("Сохранить", style = TrassirTokens.Md.Sys.Typescale.labelLarge, color = TrassirTokens.Md.Sys.Dark.onPrimary)
TrassirTokens.swift — iOS · SwiftUI

Сгенерированный код. Имена повторяют текущий TrassirUIKit, поэтому замена делается поиском.

swift
// ios/Sources/TrassirTokens/TrassirTokens.swift — фрагмент, полный файл в пакете
import SwiftUI

public enum TrassirTokens {
    public enum Tr {
        // Цвета TrassirUIKit. В комментарии — старое имя: переезжать можно постепенно
        public enum Color {
            /// В коде: TrColor.primary. Конфликт «primary», значение не сведено.
            public static let primary: SwiftUI.Color = SwiftUI.Color(.sRGB, red: 115.0 / 255.0, green: 103.0 / 255.0, blue: 240.0 / 255.0, opacity: 1)
            /// В коде: TrColor.grayscale800. Конфликт «surfaceContainer», значение не сведено.
            public static let grayscale800: SwiftUI.Color = SwiftUI.Color(.sRGB, red: 36.0 / 255.0, green: 36.0 / 255.0, blue: 36.0 / 255.0, opacity: 1)
        }
        // Шрифты. Межстрочного и трекинга в коде приложения нет — помечено TODO
        public enum Typography {
            /// В коде: TrTypography.Style.ndButton. TODO: в коде нет letterSpacing, lineHeight.
            public static let ndButton: SwiftUI.Font = SwiftUI.Font.system(size: 14, weight: .medium)
        }
        public enum Radius {
            /// В коде: ModuleConstants.Visual.cornerRadiusNewDesign.
            public static let cornerRadiusNewDesign: CGFloat = 10
        }
        public enum Size {
            /// В коде: ModuleConstants.Visual.buttonHeightNewDesign.
            public static let buttonHeightNewDesign: CGFloat = 44
        }
    }
}

// Как использовать
Text("Сохранить")
    .font(TrassirTokens.Tr.Typography.ndButton)
    .frame(height: TrassirTokens.Tr.Size.buttonHeightNewDesign)
    .background(TrassirTokens.Tr.Color.primary)
    .cornerRadius(TrassirTokens.Tr.Radius.cornerRadiusNewDesign)
